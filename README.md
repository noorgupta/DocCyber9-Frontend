# DocCyber Frontend

Frontend application for the **DocCyber Document Integrity Verification System**, providing a secure interface to store and verify document integrity.

## Features

- User Registration
- User Login
- JWT Authentication
- Store Text Documents
- Store File Documents
- Verify Document Integrity
- Detect Tampered Documents
- Responsive Interface

| Category | Technologies |

## Installation

```bash
git clone https://github.com/noorgupta/DocCyber9-Frontend.git

cd DocCyber9-Frontend

npm install

npm run dev
```

---

## Environment Variable

```env
VITE_API_URL=https://doccyber9-backend.onrender.com
```
